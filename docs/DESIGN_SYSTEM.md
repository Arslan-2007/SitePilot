**Version:** 1.0

**Owner:** Design Team  
**Last Updated:** July 2026

---

# 1. Design Philosophy

SitePilot should feel:

- Professional
- Intelligent
- Modern
- Premium
- Fast
- Trustworthy

The interface should never feel cluttered or playful.

Every element should have a purpose.

---

# 2. Visual Inspiration

Our design quality should be comparable to modern SaaS platforms known for clean interfaces and strong developer experiences.

We are inspired by:

- Minimal layouts
- Spacious spacing
- Clear typography
- Subtle motion
- Soft shadows
- Professional dashboards

We DO NOT copy their UI.

We only follow the same design philosophy.

---

# 3. Theme Strategy

Dark Mode is the primary experience.

Light Mode is fully supported.

Users can choose:

- Light
- Dark
- System

Theme selection is remembered.
